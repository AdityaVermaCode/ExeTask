# 🚀 ExeTask

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

A custom, glassmorphic cyber task manager that runs directly on your Windows desktop. Track your tasks, drag it anywhere, minimize it out of sight, and enjoy a high-fidelity vibe while working. Built using modern desktop web frameworks.

---

## ✨ Features

- 💎 **Glassmorphic UI:** Modern, clean, translucent cyber interface.
- 📦 **Desktop Native:** Fully draggable, minimizable, and responsive right on your Windows desktop.
- ⚡ **Lightweight:** Runs instantly on your machine using optimized background routines.

---

## 🛠️ Prerequisites

Before getting started, you need to have the following environment setup:

- **Operating System:** Windows 10 or 11 (Recommended)
- **Runtime Environment:** [Node.js](https://nodejs.org) (Required for executing the Electron desktop environment)

---

## ⚙️ How to Use ExeTask From This Repository

Follow these step-by-step instructions to get ExeTask running locally on your computer.

### Step 1: Download the Code
Open this GitHub repository URL in your web browser, click the green **Code** button, and select **Download ZIP**. Extract the downloaded folder onto your computer.

*Alternatively, if you are familiar with Git, you can open your terminal and run:*
```bash
git clone https://github.com
```

### Step 2: Install Node.js
Because Electron apps require a runtime setup to execute, you must have **Node.js** installed on your computer. If you don't have it yet, download it for free from [nodejs.org](https://nodejs.org).

### Step 3: Run the Launch Commands
Open your terminal (**Command Prompt** or **PowerShell**) inside your extracted project folder and run these two quick commands:

```bash
# 1. Download the safe background packages (Electron framework)
npm install

# 2. Launch the app instantly right on their desktop
npm start
```

---

## 🎉 The Result

The terminal will download Electron automatically and open your custom **glass cyber task manager** directly onto your Windows desktop! You can drag it around, minimize it, and type your tasks out seamlessly.
